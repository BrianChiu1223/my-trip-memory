# 途屿 · Our Little Atlas

世界很大，我们慢慢走。一个用来收藏两个人的旅行足迹、照片与故事的网站。

本仓库：[`BrianChiu1223/my-trip-memory`](https://github.com/BrianChiu1223/my-trip-memory)。本轮开发分支为 `codex/travel-memory-demo`。

## 先看 Demo

在项目目录运行：

```sh
# 首次下载项目时安装依赖；当前工作区已安装
npm run setup

# 启动本地网站
npm run dev
```

打开 <http://localhost:3000>。如果端口被占用，开发服务器会打印实际地址；也可用 `PORT=3001 npm run dev` 指定。建议长期使用同一地址：`localhost` 与 `127.0.0.1`、不同端口的浏览器数据相互独立。

需要 Node.js >= 22.13，推荐 Node.js 24 LTS。启动脚本会优先使用当前 Node；若版本过旧且这台电脑已有 Codex 自带的新版 Node，会自动使用该运行时，不修改系统 Node 设置。

## 已实现

- **世界足迹地图**：已去国家高亮，按国家下钻到城市点位，城市打开旅行；提供缩放、放大后拖动、重置和国家列表入口。
- **旅行手记**：旅行封面、出发与返程日期、多国家 / 多城市、描述、分段日记、标签；支持新增、编辑、删除与珍藏。
- **时光相册**：照片墙、灯箱、前后切换和键盘左右键浏览。
- **时间线**：按出发年份分组，同一份旅行记录同步显示。
- **筛选**：搜索城市、日记或标签，按年份 / 国家筛选，仅看珍藏。
- **心愿清单**：新增与移除下一站目的地。
- **照片上传**：JPG / PNG / WebP，单张最多 20MB，每次旅行最多 20 张；旋正方向、缩到长边不超过 2000px，并生成 JPEG 浏览副本。
- **本机持久化**：IndexedDB 保存旅行和照片 Blob，成功写入后更新界面；照片与记录通过同一事务保存。
- **完整备份**：页面底部“备份与关于”可导出包含本地照片的 JSON，也可校验后恢复。恢复前会明确提示替换当前数据。
- **响应式样式**：桌面双栏布局、手机底部四项导航；支持减少动效偏好、原生 dialog 键盘关闭与焦点管理。

初始提供 **6 段示例旅行、4 个国家、9 座城市、16 条照片记录**。均为虚构演示内容，不代表用户真实经历；部分示例照片会在不同记录中重复出现。所有展示素材均保存在仓库，Demo 运行时不请求在线地图瓦片、外部字体或图片网站。

## 先试这几步

1. 在地图底部点击“中国”或“日本”，看城市足迹；点击城市，打开旅行故事。
2. 切换“旅行手记 / 时光相册 / 时间线”，查看同一批回忆的不同样子。
3. 点击“记录旅行”，填写日期，选一个或多个城市，上传几张测试照片后保存。
4. 刷新页面，再在手记或相册中找到新记录。
5. 从“备份与关于”导出完整备份；如要测试恢复，先导出当前内容再恢复。

以上为体验指引，不代表已完成浏览器自动化验收。当前环境的浏览器安全策略拒绝访问本地预览，自动截图、点击流程与真实手机测试尚未执行。

## 本地演示的限制

**这还不是已经上线的双人私密云端服务。** Demo 没有真实登录、云数据库、跨设备同步或自动云备份。

数据只属于当前浏览器和当前来源地址。清除站点数据、更换设备或浏览器会使本地记录不可用；请自行保留照片原图并定期导出备份。照片压缩副本不替代原图存档。HEIC / Live Photo / 视频未实现，HEIC 需要先转换为支持格式。

地点选择目前提供 15 个国家 / 地区的精选城市，未接入全球地点搜索。国家地图是 Natural Earth 世界边界的放大示意，没有省州或城市行政区填色、真实导航路线，也没有全球城市边界数据。

删除 Demo 旅行会移除记录及其不再被引用的本地照片，无回收站；恢复备份会替换本地记录。正式版计划采用软删除、恢复期和独立备份。

请勿把真实照片、日记、账号凭据和备份文件提交到当前公开 GitHub 仓库。

## 技术方案

完整中文方案见 [docs/TECHNICAL_PLAN.md](docs/TECHNICAL_PLAN.md)，包括：

- 产品与地图层级、解锁计数定义、跨国多城市数据模型。
- 推荐正式 MVP：稳定 Next.js / React / TypeScript + Supabase Auth / PostgreSQL / 私有 Storage。
- 两个预邀请成员、RLS、并发更新、短期签名媒体地址与私有缓存策略。
- 原图 / 展示图 / 缩略图，HEIC、EXIF、断点上传、处理队列、删除一致性。
- 数据库和照片的独立备份、迁移、域名与 HTTPS、国内网络实测。
- 按照片规模计算的预算、R2 的引入时机、实施阶段和上线验收。

本地采用 Sites 提供的 **Vinext 1.0.0-beta.5 / React 19 / TypeScript / Vite** 模板；地图为 `d3-geo + topojson-client + world-atlas`，图标为 Lucide。保留模板的 Sites / Worker 适配文件，当前未注册或发布任何 Site，也未接入 D1、R2 或 ChatGPT 登录。
